## 可重复命令

```text
pnpm test
pnpm build
cargo test --manifest-path src-tauri/Cargo.toml
cargo check --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml --check
pnpm tauri build
pnpm run runtime:webview2
pnpm run package:portable
pnpm run verify:portable
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-portable.ps1 -LaunchCheck
cargo test --manifest-path src-tauri/Cargo.toml --release customers_ten_thousand_list_p95_stays_under_three_hundred_ms -- --ignored --nocapture
pnpm run perf:release
```

导入失败行文件命名为 `import-failed-<batch_id>.csv`；保护模式下扩展名为 `.csv.enc`，内容使用同一 `ERPENC1` 封装。文件包含原始字段、行号和错误原因；选择“任一失败则回滚”时，结果报告中的 `rolled_back` 为 `true`，数据库不保留该批次成功行。

P0-05 自动化用例：`damaged_uninitialized_database_restores_from_manifest_and_keeps_quarantine`、`protected_restore_rewrites_encrypted_database_shadow`、`manifest_checksum_mismatch_is_rejected_before_restore`、`backup_scan_works_without_an_open_database`、`failed_restore_keeps_corrupt_source_and_cleans_restore_temps`。
