# P0-04/P0-11 Windows release 文件占用重试记录
- 日期：2026-09-15
- 版本：V1.2.3 release
- 范围：本机 Windows 隔离临时账套。
- 注：使用独占文件句柄模拟占用；不等同于 Office、杀毒软件或真实磁盘空间不足。

## 操作与结果

1. 使用辅助进程以共享读方式锁定 `backup/manifest.json`，先验证其他进程无法以独占读写方式打开该文件。
2. 在 ERP 中执行“立即备份”。备份文件生成并保留，但清单登记失败；“基础设置 → 备份与恢复”显示“备份未完成”，明确说明文件已生成、清单写入失败、文件路径和“重试备份”入口。证据：`P0-04-manifest-lock-backup-error.png`。
3. 释放锁定进程后点击“重试备份”。备份列表出现新的校验通过文件，清单条目数量更新；未发现 `.tmp`、`.snapshot` 或 `.part` 残留。证据：`P0-04-manifest-lock-backup-retry.png`。
4. 正常退出后进程数为 0，`last_exit.status=clean`；最新 253,952 字节备份的清单 SHA-256 与实际文件一致，SQLite `PRAGMA integrity_check` 返回 `ok`。

## 结论边界

本次验证覆盖 Windows 原子替换目标被占用时的“保留已生成文件、登记失败提示、释放后重试”路径；真实 Office/杀毒软件占用、目录权限拒绝、磁盘空间不足和并发导出仍需目标设备现场演练。
